# Поисковая подготовка сайта

## Что реализовано

- 43 страницы с полноценным HTML: главная, каталог, пять разделов, 12 исходных изделий, шесть проектов скамеек, три проекта фонарей и три проекта люков, производство, новые направления с пятью отдельными страницами, заказ и доставка, контакты.
- Обычные ссылки на товары и категории. Текст, характеристики, фотографии и контакты доступны без JavaScript.
- Уникальные заголовки страниц и описания, один H1, семантические разделы и хлебные крошки.
- Абсолютные canonical, Open Graph и карточки для публикации ссылок.
- JSON-LD Organization, WebSite, WebPage, BreadcrumbList, CollectionPage/ItemList. Изделия размечены Product; модели и проекты — CreativeWork; промышленное литьё — Service.
- Цены, Offers, отзывы, рейтинги, складское наличие, адрес и сроки не выдумывались. Без цены/предложения либо отзывов разметка Product не претендует на расширенный товарный результат Google.
- XML Sitemap, файл robots.txt, страница 404 с noindex, читаемые адреса, alt, размеры изображений, отложенная загрузка изображений ниже первого экрана.
- Локальные CSS и JavaScript, системный шрифт, отсутствие внешних библиотек и трекеров.

Основной индексируемый адрес в `site.config.json`: https://csm-lit.ru/ . Все canonical и Sitemap указывают на него. Домен приобретён владельцем 23.10.2026; готовность DNS и HTTPS проверяется отдельно по [инструкции подключения](domain.md).

Копия на https://centrspetsmetall.a9252233314.chatgpt.site/ сохраняет прежний доступ только для владельца. Сайт за авторизацией поисковый робот не индексирует. Настройки доступа автоматически не менялись.

`robots.txt` действует в корне домена: `https://csm-lit.ru/robots.txt`. Sitemap находится по адресу `https://csm-lit.ru/sitemap.xml`. Доступность индексирования задаётся также метатегами страниц.

## Перед полноценным продвижением

1. Завершить подключение купленного домена `csm-lit.ru`: DNS, сертификат HTTPS и перенаправления GitHub Pages. `canonicalBase` и сгенерированные страницы уже подготовлены под новый домен.
2. Город производства подтверждён: Тула, Тульская область. Указан на сайте и в PostalAddress организации; точный уличный адрес не назначен. Контакты для интернет-заказов подтверждены владельцем 23.10.2026: Роберт, +7 (926) 391-06-55, info@brassart.ru. Юридические сведения остаётся подтвердить.
3. Подтвердить права на сайт в Яндекс Вебмастере и Google Search Console, передать `sitemap.xml` и проверить доступность страниц. Учётные записи и коды подтверждения в этой задаче не предоставлены.
4. При необходимости подключить аналитику и учёт заявок с реальными идентификаторами. Никакие фиктивные счётчики не подключены.
5. Согласовать реальные цены, комплектации, сроки и условия доставки. Добавлять Offer/наличие только после подтверждения и поддерживать их актуальными.

Форма составляет письмо, позволяет скопировать и скачать текст. Отправка выполняется посетителем через свою почту; серверной CRM и автоматической отправки заявок нет.

SEO-подготовка не означает гарантированной индексации или места в поиске. После публикации требуется проверка в кабинетах поисковых систем и работа с реальными предложениями и спросом.
