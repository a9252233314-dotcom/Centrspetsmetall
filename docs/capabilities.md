# Производственные возможности ЦЕНТРСПЕЦМЕТАЛЛ

Сведения из предоставленных компанией презентации и перечня оборудования.

## Масса отливок

| Материал | Предельная масса |
| --- | --- |
| Сталь | до 500 кг |
| Чугун | до 700 кг |
| Медь, бронза, латунь | до 700 кг |
| Алюминий | до 300 кг |

Возможность изготовления конкретной детали подтверждается после рассмотрения геометрии, сплава и требований заказа.

## Плавильное оборудование

| Оборудование | Вместимость по исходному документу |
| --- | --- |
| Дуговая печь | до 400 кг по чугуну |
| Индукционная печь | По стали |
| ИСТ 0,06, сдвоенная | до 70 кг по стали |
| ИСТ 0,4 со сменным плавильным узлом | до 400 кг по стали |
| Газовые печи | 10 / 20 / 30 кг по меди |
| Газовоздушная масляная печь | до 30 кг по меди; в документе также указана плавка чугуна |

Вместимость печи и предельная масса готовой отливки — разные параметры.

## Формовка и обработка

- Формовка ПГС, ЖСС, ХТС; бегуны и смесители ХТС.
- Машина литья под давлением, 6-я серия.
- Две печи отжига.
- Пескоструйная и дробеструйная установки.
- Два галтовочных барабана.
- Обычная и порошковая покраска.
- Центробежное литьё втулок из бронзы, латуни и алюминия до Ø320 мм; большие диаметры рассматриваются в формах ПГС / ХТС.
- Модельная оснастка, промышленные и художественные отливки по чертежам, образцам и эскизам.
