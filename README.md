## Структура

23 статические страницы: главная, каталог, пять категорий, 12 изделий, производство, новые направления, заказ и доставка, контакты. Текст, характеристики, фотографии и ссылки доступны без JavaScript.

- `products.json` — описания, статусы и фотографии изделий.
- `site.config.json` — основной адрес, контакты и дата обновления.
- `build_site.py` — генератор статических HTML, Sitemap и страницы 404.
- `modern.css` — адаптивный дизайн.
- `modern.js` — меню, поиск, галерея, увеличение фото и подготовка заявки.
- `catalog/`, `products/`, `production/`, `blagoustroystvo/`, `delivery/`, `contacts/` — готовые страницы.
- `sitemap.xml`, `robots.txt`, `404.html` — файлы поисковой подготовки.
- `assets/` — фотографии, логотип и публичные документы компании.

## Локальная работа

Нужны Python 3 и Pillow. После изменения каталога, шаблонов или адреса выполните:

```powershell
python build_site.py
python -m http.server 8000
```

Откройте http://localhost:8000 . Для просмотра уже сгенерированного сайта зависимости в браузере не нужны.

Для нового товара добавьте сведения и фотографии в `products.json`, человекочитаемый адрес в `SLUGS` генератора, затем пересоберите сайт. Не используйте неподтверждённые характеристики, цены или наличие.

## Публикация обоих адресов

GitHub Pages публикует ветку `main`, папку `/ (root)`. Коммитьте сгенерированные страницы вместе с исходниками.

Копию Sites необходимо обновлять отдельно: синхронизировать файлы сайта в `../Centrspetsmetall/dist/`, сохранить существующий `.openai/hosting.json` и настройки доступа, выполнить поддерживаемую публикацию Sites. Обновление GitHub само по себе не меняет `chatgpt.site`.

Основной адрес для canonical и Sitemap задаёт `canonicalBase`. При подключении собственного домена измените его, пересоберите сайт и настройте домен и перенаправления на хостинге. Файл robots.txt проекта GitHub Pages не управляет корнем общего домена; подробности в [SEO-документации](docs/seo.md).

## Заявки

Форма подготавливает письмо на `csm-factory@bk.ru`, позволяет скопировать или скачать текст. Посетитель отправляет его из своей почты и прикрепляет файлы. Есть прямые ссылки на телефоны и почту. Серверная отправка, оплата и CRM не подключены.

В письмо включается адрес страницы обращения для различения источников заявок. Телефон или email обязателен; данные не сохраняются на сервере сайта.
