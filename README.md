## Аналитика

На всех публичных HTML-страницах установлен предоставленный код Яндекс.Метрики № 113775985 с Вебвизором, картой кликов, отслеживанием ссылок и ecommerce-контейнером `dataLayer`. Общая вставка — `analytics.py`; генераторы сохраняют счётчик при последующей сборке. Инициализация выполняется один раз на страницу, резервный пиксель находится в `body`.

Для подтверждения прав в Яндекс.Вебмастере в корне находится `yandex_7c4f37520b263d9f.html`. Служебный файл публикуется без оформления и кода аналитики.

Для Google Search Console в корне размещён файл `google5c5e5f591b0ed8d2.html` с исходным содержимым, без оформления и аналитики.

## Структура

45 статических страниц: главная, каталог, пять категорий, 12 исходных изделий и проект банной печи Б01, шесть проектов скамеек, три проекта фонарей и три проекта люков, производство с тремя страницами услуг, новые направления с пятью отдельными страницами, заказ и доставка, контакты и реквизиты. ## Бренд и организация

С 24.10.2026 сайт оформлен под брендом «Тульская литейная мануфактура», юридическое лицо — ООО «Сфералит». Реквизиты перенесены из предоставленной карточки организации; подпись и служебный комментарий из исходного документа не публикуются. Данные находятся в `site.config.json`, раздел `legalEntity`. Публичная страница — `/requisites/`, карточка для скачивания — `assets/tlm-requisites.pdf`.

Эмблема взята из предоставленного файла «ТЛМ.jpg». `assets/tlm-logo.svg` использует viewport для отображения лицевой эмблемы без окружающей технической схемы, исходное изображение сохранено отдельно. Исходные презентация и перечень оборудования сохранены как переданные производством документы; старое название репозитория и домен не менялись.

Перенос на обычный хостинг подготовлен отдельно. Доступ к целевому хостингу и новый IP пока не предоставлены; DNS не менялся. На сервер загружаются готовые страницы и публичные ресурсы, Python и база данных для текущего сайта не нужны.

- `products.json` — описания, статусы и фотографии изделий.
- `site.config.json` — основной адрес, контакты и дата обновления.
- `build_site.py` — генератор статических HTML, Sitemap и страницы 404.
- `modern.css` — адаптивный дизайн.
- `modern.js` — меню, поиск, галерея, увеличение фото и подготовка заявки.
- `catalog/`, `products/`, `production/`, `blagoustroystvo/`, `delivery/`, `contacts/` — готовые страницы.
- `sitemap.xml`, `robots.txt`, `404.html` — файлы поисковой подготовки.
- `assets/` — фотографии, логотип и публичные документы компании.

## Локальная работа

Нужны Python 3 и Pillow. После изменения каталога, шаблонов или адреса выполните:

```powershell
python build_site.py
python -m http.server 8000
```

Откройте http://localhost:8000 . Для просмотра уже сгенерированного сайта зависимости в браузере не нужны.

Для нового товара добавьте сведения и фотографии в `products.json`, человекочитаемый адрес в `SLUGS` генератора, затем пересоберите сайт. Не используйте неподтверждённые характеристики, цены или наличие.

## Публикация обоих адресов

GitHub Pages публикует ветку `main`, папку `/ (root)`. Коммитьте сгенерированные страницы вместе с исходниками.

Копию Sites необходимо обновлять отдельно: синхронизировать файлы сайта в `../Centrspetsmetall/dist/`, сохранить существующий `.openai/hosting.json` и настройки доступа, выполнить поддерживаемую публикацию Sites. Обновление GitHub само по себе не меняет `chatgpt.site`.

Основной адрес для canonical и Sitemap — `https://csm-lit.ru/`, он задан в `canonicalBase`. Файл `CNAME` закрепляет домен за публикацией GitHub Pages. DNS и HTTPS требуют отдельной проверки; настройки приведены в [инструкции подключения домена](docs/domain.md). Копия Sites обновляется отдельно.

## Проекты скамеек

`benches.json` и `bench_catalog.py` содержат описания и исходную геометрию шести моделей. Генератор создаёт визуализации, схемы и JSON для поворота моделей в браузере. `bench-catalog.css` и `bench-viewer.js` отвечают за представление и интерактивный выбор. В каталоге теперь 24 позиции, из них шесть — эскизные проекты скамеек. PDF-эскизы находятся рядом с SVG в `assets/benches/`; обновление PDF описано в [документации коллекции](docs/bench-collection.md).

Новые профили «Дуга», «Поток» и параметрический «Ритм» создаются `modern_benches.py` по собственным формулам. В «Ритме» можно сравнить 21/25/29 деревянных рёбер; их изготовление рассматривается отдельным этапом. Перед сборкой проверяйте все варианты командой `python tools/check_bench_geometry.py`.

## Проекты фонарей

`lamps.json`, `lamp_geometry.py` и `lamp_catalog.py` формируют три собственных проекта. Высота меняется без масштабирования плафона и цоколя; «Ореол» позволяет сравнить 12/16/20 рёбер. Рендеры, PDF, геометрические проверки и ограничения описаны в [документации коллекции](docs/lamp-collection.md).

## Проекты люков

`hatches.json`, `hatch_geometry.py` и `hatch_catalog.py` создают три собственных эскиза крышек и рам. Доступны отдельные детали, разнесённая сборка и параметрические варианты рельефа. Размеры, воспроизведение рендеров, PDF, геометрические проверки и ограничения описаны в [документации коллекции](docs/hatch-collection.md).
